구현 범위: 10개 기능(UC-01 ~ UC-10)을 모두 구현했다. 게임 시작, 매수/매도, 30턴 진행, 뉴스와 가격 변동, 결과 판정(엔딩, 투자 성향, 업적), 기록 저장과 조회가 한 판 안에서 끝까지 동작한다.
검증: 외부 라이브러리 없이 실행하는 규칙 테스트(test/superant/RuleTest.java) 42개가 모두 통과했다. 가격 반올림, 20% 상한, 평균 원가 배분, 시드 재현성, 입력 검증, 거래 거절, 중복 요청, 30턴 완주와 기록 저장/중복 저장 방지, 칭호 경계값을 확인한다.
화면 연출: 턴 마감을 누르면 약 2초 동안 장중 애니메이션이 재생된다. 가격이 틱 단위로 오르내리고 셀이 빨강/파랑으로 깜빡이며 차트에 LIVE 표시가 뜬다. 경로는 화면 표시 전용이고 마지막 값은 항상 미리 추첨된 종가와 같아 규칙과 결과에는 영향이 없다. 보유 종목은 시장 표의 민트 막대, 종목 상세의 "내 보유" 줄, 상단의 보유 종목 수와 평가손익으로 바로 확인할 수 있다.
칭호와 턴 결과: 게임 중 수익률에 따라 칭호가 개미굴 개미, 새내기 개미, 일개미, 병정개미, 여왕개미(20% 이상), 슈퍼개미(50% 이상)로 실시간으로 바뀐다. 엔딩 3종의 판정 기준은 그대로이며, 수익 달성 엔딩의 결과 칭호만 수익률 50% 이상일 때 "슈퍼개미 등극!", 그 밖에는 "여왕개미 등극!"으로 표시한다. 장 마감 직후에는 이번 턴 손익, 최고 상승/최대 하락 종목, 칭호 변화, 연속 수익 턴 수를 카드로 보여 준다.
속보와 효과음: 뉴스가 있는 턴이 시작되면 BREAKING 배지가 깜빡이고 뉴스 제목이 한 글자씩 타이핑된다. 매수/매도 체결, 상승/하락 마감, 칭호 상승, 속보, 주문 거절, 게임 결과에 효과음이 나며, 외부 사운드 파일 없이 Sfx 클래스가 사인파를 직접 합성한다. 하단 "소리" 버튼으로 끌 수 있고 사운드 장치가 없으면 조용히 건너뛴다.
단순화 1: 요청 중복 방지는 화면 version 비교를 기본으로 하고, requestId 는 최근 200개까지만 메모리에 기억한다.
단순화 2: 기록 파일은 임시 파일에 먼저 쓴 뒤 교체하는 방식으로만 원자성을 보장하며, 여러 프로그램이 동시에 저장하는 경우의 파일 잠금은 다루지 않는다.
단순화 3: 기록 파일이 손상되면 자동 복구 없이 오류 메시지를 보여 주고 저장을 중단한다(기존 파일은 덮어쓰지 않음).
단순화 4: 화면 해상도는 1180 x 760 이상을 기준으로 배치했고, 접근성(키보드 전용 조작, 고대비 모드)은 정식 버전 과제로 남겼다.
실행 방법: JDK 17 이상에서 java -jar ssd_ip_cp4_2026f_244489_app.jar. 기록은 %APPDATA%\stock-game\records.json 에 저장된다.
AI 활용: 설계 문서 정리, 다이어그램 생성 스크립트, 코드 초안 작성에 AI 도구(Claude)를 활용했고, 모든 규칙은 CP3 요구사항과 대조해 직접 검토하고 테스트로 확인했다.
